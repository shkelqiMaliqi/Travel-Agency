Use the supplied six-page 2026 PDF as the requirements authority. Its deadline is 8 January 2027. One student uploads on behalf of the group; every member attends the practical defense.

- Run the backend, frontend, browser, and build commands in README.md; keep actual results.
- Demonstrate Kubernetes and the required cache, queue, load balancing, and monitoring in the target environment. A source file or manifest alone is not runtime evidence.
- Run the advanced CI/CD workflow and retain the GitHub run/artifact link. Publication/deployment requires its environment configuration.
- Update `VERIFICATION_2026-11-16.md` when additional checks actually execute; do not copy historical successes into current results.
- Complete `TEAM_CONTRIBUTIONS.md` and personal academic declarations; disclose AI assistance accurately.
- Rehearse the startup, endpoint/database demo, error/permission cases, tests, architecture, and individual explanation from `PRESENTATION_GUIDE.md`.
- Run `python Tools/package-submission.py` and inspect its manifest. It excludes secrets/dependencies/logs and obsolete documentation copies.
- Review the Word report if included and ensure it agrees with current verification.
- Upload the resulting archive/materials to Moodle personally and retain confirmation. Submission, attendance, and instructor approval cannot be automated from this repository.
